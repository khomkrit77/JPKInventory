# Browser acceptance checklist

- เปิด http://localhost:5173: พบ 11 อุปกรณ์ (Router 4, Server 1, NAS 1, PC 2, Notebook 3) ผู้ใช้ 5 คน และ Sites ครบ 4 แห่ง
- Dashboard: HQ 5 เครื่อง, AKM/RYT/RST สาขาละ 2; คลิกแต่ละ Site แล้วกรอง Devices ตรงสาขา
- เลือกประเภทและ Site พร้อมพิมพ์ค้นหา ตรวจกรณีไม่พบผลลัพธ์
- เพิ่ม PC/Notebook กรอกทุกช่อง เลือก Owner เพิ่ม Folder 2 รายการ เลือก Read/Write และลบหนึ่ง Folder บันทึก แก้ไขเพื่อตรวจค่าครบ รีโหลดและตรวจว่าคงอยู่
- กรอก IP เป็น 999.1.1.1 และ MAC ผิดรูปแบบ ต้องมีข้อผิดพลาดใต้ฟอร์มและไม่บันทึก; กรอกค่าถูกแล้วบันทึกได้; MAC เว้นว่างได้; ทดสอบ End MA ก่อน Start MA และ Hostname ซ้ำ
- เปลี่ยนประเภทจาก PC ที่ Site AKM เป็น Server/NAS ต้องล็อก HQ และซ่อนช่อง PC; เปลี่ยนกลับเป็น Router ต้องเลือก Site ได้
- เพิ่ม/แก้ไข User แล้วเชื่อม Owner; เปลี่ยนชื่อ User และตรวจชื่อใหม่ที่ Devices; ลบ User ที่ถูกใช้งานต้องเตือนและล้าง Owner หลังยืนยัน
- ลบอุปกรณ์: ยกเลิกต้องยังอยู่ ยืนยันต้องหายและยอด Dashboard ลดตาม
- กด Escape ปิด dialog; ใช้ Tab/Shift+Tab และ Enter; ตรวจ focus กลับปุ่มเดิม
- ตรวจความกว้าง 1440, 1024, 768, 390 และ 320px ไม่เกิด horizontal overflow; mobile เมนูเปิดปิดและตารางเปลี่ยนเป็นการ์ด
- DevTools: ตั้ง localStorage key jpk-inventory:v1 เป็นข้อความที่ไม่ใช่ JSON แล้วรีโหลด ต้องแสดงข้อผิดพลาดโดยไม่เขียนทับ; คืนค่าหรือลบ key แล้วรีโหลด
- เปิดสองแท็บแล้วแก้ไขหนึ่งแท็บ ตรวจอีกแท็บรับข้อมูลใหม่และปิดฟอร์มเก่า
- ตรวจ Console ไม่มี error ระหว่างการใช้งาน; ทดสอบ Docker URL http://localhost:8080 แยกจาก Python origin

## v1.1 additions / migration

- ใช้ข้อมูล version 1 ที่เคยบันทึกไว้ เปิดไฟล์เดิมด้วยเบราว์เซอร์เดิม ตรวจว่ารายการ/ID/Owner/Folder เดิมยังอยู่ทั้งหมด; ผู้ใช้มีโทรศัพท์/หมายเหตุว่าง และ Antivirus แสดงยังไม่ระบุ
- Sites > เพิ่ม Site: กรอก bkk2 และชื่อสาขา ต้องได้ BKK2; ลอง HQ/hq ซ้ำหรือรหัสมีช่องว่าง ต้องไม่บันทึก; ตรวจ sidebar และ dropdown อุปกรณ์/ผู้ใช้มีสาขาใหม่ทันทีและหลัง reload
- เพิ่มอุปกรณ์ประเภทอื่นๆ ชื่อประเภท “UPS สำรองไฟ” ที่ BKK2; บันทึก ตรวจ Dashboard, Site BKK2 และ Devices; ค้นหา “สำรองไฟ” และกรองอื่นๆ+BKK2; แก้ไขแล้วค่าคงอยู่
- เปลี่ยนประเภทอื่นๆ เป็น PC และสลับ Server/Router/NAS: ช่องประเภทกำหนดเองแสดงเฉพาะอื่นๆ; Antivirus เฉพาะ PC/Notebook/Server; Server/NAS ล็อก HQ; บันทึกเฉพาะฟิลด์ของประเภทนั้น
- เพิ่ม/แก้ไข PC/Notebook/Server ต้องเลือก Antivirus Yes/No; ตรวจป้าย AV ในรายการและปุ่มดูรายละเอียด; อุปกรณ์ประเภทอื่นไม่มี AV
- เพิ่มโทรศัพท์และหมายเหตุแบบหลายบรรทัดให้ User; บันทึก แก้ไข reload ตรวจแสดงที่การ์ดและค้นหาได้; ทดลองข้อความ <img src=x onerror=alert(1)> ต้องแสดงเป็นข้อความ
- Issue Logs: เพิ่มปัญหาเลือกอุปกรณ์และ Users เดิม ใส่วันที่เกิดและ Notes เว้นวันที่แก้ ต้องเป็น Open; ดูรายละเอียด แล้วแก้ไขเพิ่มวันที่แก้ ต้องเป็น Resolved
- เลือกอื่นๆ ที่อุปกรณ์/Service และผู้แจ้ง ช่องชื่อปรากฏและบังคับกรอก; สลับกลับเลือกจากรายการ ช่องชื่อซ่อนโดยไม่สร้าง reference ผิด
- โครงสร้างเดิมไม่มี Service catalog: ต้องเลือกชื่อ Service ผ่านอื่นๆ ได้; หากมี services ในข้อมูล ตัวเลือกต้องแสดงชื่อและบันทึก reference ได้
- ลองไม่กรอกฟิลด์บังคับ, วันที่แก้ก่อนวันที่เกิด, วันที่ที่ไม่มีจริง ต้องมีข้อความในฟอร์มและไม่บันทึก
- เพิ่มหลาย Issue แล้วค้นหา Notes/ผู้แจ้ง/อุปกรณ์ กรอง Open/Resolved, วันที่เริ่ม=สิ้นสุด และอุปกรณ์/Service พร้อมกัน; วันที่เริ่มหลังสิ้นสุดต้องมีข้อความเตือน; ล้างตัวกรองคืนรายการ
- ลบ Issue: ยกเลิกต้องยังอยู่ ยืนยันต้องหาย; ลบอุปกรณ์/ผู้ใช้ที่ถูกอ้างใน Issue ต้องเตือนและเก็บชื่อแบบอื่นๆ โดยยังเปิด/แก้ไข Issue เดิมได้หลัง reload
- ตรวจ responsive ทุกหน้า โดยเฉพาะตัวกรอง Issue Logs และการ์ดประเภทอื่นๆ ชื่อยาว; ใช้ keyboard เปิด/ปิด dialog และตรวจการแสดงข้อผิดพลาด
